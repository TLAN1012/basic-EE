# Basic EE · 基礎電子學自學網站

以繁體中文、課程式的節奏自學基礎電子學。假設你已經懂電壓、電流、串聯與並聯。

## 六課

1. 歐姆定律與功率
2. 分壓器與負載效應
3. 電容與 RC 充放電
4. RC 濾波器：低通與高通
5. 二極體與 LED
6. NPN 電晶體：開關與放大

每一課都是同一個節奏：**為什麼要學 → 概念講解 → 導引實驗 → 自我檢測 → 重點整理與常見誤解**。

## 導引實驗怎麼運作

- 電路已經接好，不用自己接線。
- 左側「導引步驟」每一步寫明 **做什麼、你會看到、為什麼**。按「幫我設定」可直接套用該步驟的數值；達成條件時自動打勾。
- 每次調整旋鈕，電路圖、讀數、圖表都即時更新，「正在發生的事」用一句話解釋目前狀態。
- 進度（步驟與測驗）存在瀏覽器的 localStorage，沒有帳號。

## 執行

純靜態網站、ES modules，不需要安裝套件。專案根目錄執行：

```sh
python3 -m http.server 8080
```

開啟 <http://localhost:8080>。請透過 HTTP 開啟，不要直接雙擊 HTML。

要放到線上：GitHub 儲存庫 **Settings → Pages → Deploy from a branch → main → / (root)**。

## 測試

```sh
npm test
```

測試涵蓋 `physics.js` 的所有模型：歐姆、分壓與負載、RC、濾波器增益與相位、二極體（Shockley 曲線與負載線）、半波整流、BJT 三個區域、工程前綴格式化。

## 程式結構

- `index.html` / `style.css` / `app.js`：外殼、路由、步驟與測驗引擎。
- `physics.js`：純函式的教學模型（SI 單位）。
- `draw.js`：以字串產生 SVG 的電路符號與折線圖工具。
- `lessons/*.js`：每課一個檔案，包含講解文字、旋鈕、模擬、電路圖、圖表、導引步驟、測驗。
- `glossary.js`：名詞小抄。

## 模型的誠實說明

理想電阻、理想非極性電容、Shockley 模型的二極體（參數調成矽約 0.7 V、紅光 LED 約 1.9 V）、固定 VBE / VCE(sat) 與固定 β 的 NPN。忽略溫度、漏電、崩潰、Early effect 與切換暫態。目的是講清楚原理與數量級，不是取代資料表或 SPICE。
