# Basic EE · 電子實驗室

以繁體中文、互動接線與示波器自學電子學。從 RC、訊號、二極體與電晶體開始；適合已了解基本電壓、電流與串並聯的學習者。

## 開始玩

需要 Python 3。專案根目錄執行：

```sh
python3 -m http.server 8080
```

開啟 <http://localhost:8080>。不需要安裝套件、不使用外部字型或雲端 API。桌機與手機／平板皆可操作。使用 ES modules，請透過 HTTP 開啟，不要直接雙擊 HTML。

### 用 iPad 或手機線上玩

這是一個純靜態網站。可在 GitHub 儲存庫的 **Settings → Pages** 選擇 **Deploy from a branch → main → / (root)** 並儲存。發布成功後，使用 Pages 提供的網址開啟。程式碼提交本身不會自動啟用 Pages。

## 四個實驗

1. **電容的時間感**：調出 1 秒時間常數，觀察充電與經電阻放電。
2. **RC 低通濾波**：比較 0.1 fc、fc、10 fc 的輸入與輸出；圖中包含啟動暫態，數值區顯示穩態增益與相位。
3. **二極體**：正向壓降、反向截止與翻轉方向。
4. **NPN 電晶體**：改 Vin、RB、RC、β，觀察截止、放大區與負載限制的飽和。

點兩個接點連線，點電線刪除；接點與電線也可用 Tab、Enter／空白鍵操作。提示分兩階段，亦可直接接好示範電路。完成進度儲存在目前瀏覽器的 localStorage；沒有帳號與跨裝置同步。

## 模擬範圍

- 接線以節點連通性檢查。允許電阻翻轉、二極體反接；會拒絕短路、不完整與本關未支援的拓撲。
- 本版為**指定電路的教學模擬**，不是任意接線的通用 SPICE 求解器。元件位置固定；點接點完成接線。
- RC：理想 R、非極性 C、理想電源；以精確指數解與正弦輸入的精確區間解計算。暫停停止模擬時間；切換輸入保留電容電壓；「重來」才把電容歸零。
- RC 放電：輸入切換到 0 V，電容經 R 放電；不是將電路斷開。斷開電路時，理想電容保持電壓。
- RC 濾波：頻率自動以目前截止頻率的倍數設定。為使各頻率易於觀察，每 8 秒實際時間顯示 4 個訊號週期；圖中橫軸是模擬時間，非實際時間。
- 二極體：0.7 V 固定正向壓降；忽略漏電、崩潰、結電容和切換暫態。壓降讀值為 VA−VK；綠色波形為電阻後節點對地電位。
- BJT：共射極固定壓降模型，VBE=0.7 V，VCE(sat)=0.2 V。β 固定但可調；IC 受 RC 與 VCC 限制。忽略溫度、Early effect、漏電與切換暫態；不是特定 2N3904 的精確模型。
- 沒有真實元件熱損壞、電感、運算放大器、MOSFET 與自由新增元件功能。

## 驗證

需要 Node.js（支援內建 test runner）：

```sh
npm test
```

測試涵蓋 RC 時間常數、充放電、正弦解步長一致性、低通增益與相位、二極體模型、BJT 工作區域、接線方向與短路拒絕。
